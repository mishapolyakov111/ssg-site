# Результаты эксперимента

Версия набора данных: `v1.1`.

Регрессионная модель предсказывает значение отклика по признакам. Качество измерено по среднеквадратичной ошибке (RMSE) на отложенной выборке.

| Метод | RMSE | Число признаков |
|---|---|---|
| Линейная регрессия | 0.41 | 12 |
| Гребневая регрессия | 0.37 | 12 |
| Лассо-регрессия | 0.38 | 12 |

Лучший результат у гребневой регрессии, добавлен метод Лассо.
