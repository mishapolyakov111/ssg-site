# Отладка

## 1. `python` не запускается в PowerShell

- **Ошибка:** `Python ` без версии, код выхода 49, `venv` не создаётся.
- **Гипотеза:** `python` в `PATH` указывает на заглушку, а не на интерпретатор.
- **Проверка:** `py -0` показал установленные Python 3.12 и 3.13.
- **Решение:** `py -3.13 -m venv .venv`.

## 2. npm не скачивает MathJax

- **Ошибка:** `npm ERR! network If you are behind a proxy...`
- **Гипотеза:** реестр npm недоступен из этой сети, а CDN доступен.
- **Проверка:** `curl` к `cdn.jsdelivr.net` вернул файл 1.1 МБ, `pip` при этом работал.
- **Решение:** файл `tex-svg.js` один раз скачан с jsdelivr и положен в `docs/javascripts/`. Сборка `tex-svg` не требует отдельных файлов шрифтов.

## 3. Битая ссылка роняет сборку

- **Ошибка:** `WARNING - Doc file 'debug.md' contains a link 'nonexistent.md', but the target is not found` и `Aborted with 1 warnings in strict mode!`
- **Гипотеза:** это ожидаемое поведение `strict: true`.
- **Проверка:** ссылка на несуществующий файл была добавлена намеренно.
- **Решение:** ссылка удалена, сборка проходит. В CI это защищает от публикации сайта с битыми ссылками.

## 4. Healthcheck падает после успешного деплоя

- **Ошибка:** шаг Healthcheck в job `deploy-host` завершился с кодом 1, `rsync` до него отработал.
- **Гипотеза:** `HOST_SITE_URL` указан по `http`, сервер перенаправляет на `https`, а `curl` без `-L` получает 302 вместо 200.
- **Проверка:** `curl -I http://se.ifmo.ru/~s367494/` вернул `302 Moved Temporarily` с `Location: https://se.ifmo.ru/~s367494/`, `curl -I https://...` вернул `200 OK`. Поле `Last-Modified` совпало со временем деплоя, значит файлы были загружены.
- **Решение:** секрет `HOST_SITE_URL` изменён на `https://se.ifmo.ru/~s367494/`, job перезапущен.
