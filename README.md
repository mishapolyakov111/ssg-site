# ssg-site

Отчёт по заданию 3 (T1 + P5): сайт на MkDocs Material.

```bash
py -3.13 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\mkdocs serve
.venv\Scripts\mkdocs build --strict
```

Секреты для деплоя на хостинг: `DEPLOY_KEY`, `KNOWN_HOSTS`, `DEPLOY_HOST`, `DEPLOY_USER`, `DEPLOY_PATH`, `HOST_SITE_URL`.
