    T1. Сравнительный анализ генераторов¶

    Сравниваются MkDocs (Material), Sphinx (MyST-Parser, тема Furo), Pelican и Nikola. Quarto не взят: он не ставится через pip.

    Измерения¶

    Одна тестовая страница (формула, таблица, листинг, русский текст), Windows 11, Python 3.13. Версии: MkDocs 1.6.1 + Material 9.7.7, Sphinx 9.1.0 + MyST-Parser 5.1.0, Pelican 4.12.0, Nikola 8.3.3.

    Генератор Холодная сборка, с Повторная сборка, с Размер результата, КБ Внешние запросы на странице
    MkDocs Material 2.2 1.2 (полная пересборка) 4739 0 (MathJax и шрифты локально)
    Sphinx + MyST 2.5 1.9 428 1 (MathJax 4 с jsdelivr)
    Pelican 1.2 не измерялась 280 0, формулы не отрисовываются
    Nikola 9.0 2.2 3217 не проверялись

    Оговорки:

    • Сайты разного объёма. У Nikola в замер попал демо-контент из nikola init --demo, у MkDocs в размер входят 2 МБ локального MathJax. Сравнивать размер корректно только по порядку величины.
    • Время получено одним запуском, без усреднения.
    • У MkDocs в build нет инкрементального режима, он есть только в serve.

    Матрица критериев¶

    Оценка от 0 до 3: 0 — нет, 1 — только вручную, 2 — через плагин или настройку, 3 — из коробки. Оценки выставлены по документации и по этим сборкам, не все критерии проверены на практике.

    Критерий Вес MkDocs Sphinx Pelican Nikola
    Формулы LaTeX (рендеринг, нумерация, ссылки) 3 2 3 1 2
    Рисунки и таблицы с подписями и перекрёстными ссылками 2 1 3 1 1
    Исполняемый контент (ноутбуки) 2 1 3 1 2
    Библиография BibTeX 2 1 3 1 1
    Версионирование 3 3 2 1 1
    Русский поиск 3 3 1 0 0
    Многоколоночная вёрстка 1 3 2 1 1
    Экспорт в PDF 1 1 3 1 1
    Автодокументирование кода 1 2 3 0 0
    Простота настройки и скорость 2 3 2 3 2
    Сумма с весами (максимум 63) 44 49 22 22

    Что не подтверждено измерением: версионирование в Sphinx, русский поиск в Sphinx (в Furo лежит только JS-поиск Sphinx с английским стеммером), BibTeX и нумерация формул у всех, кроме MkDocs.

    Обоснование весов¶

    Для публикации результатов эксперимента важнее всего формулы, воспроизводимость и версии результата (вес 3). Русский поиск тоже вес 3, потому что текст на русском. PDF и колонки второстепенны (вес 1).

    Вывод¶

    По сумме выигрывает Sphinx (49), MkDocs Material следует за ним (44). Для этого задания выбран MkDocs Material:

    • нужные для P5 версионирование (mike) и русский стемминг работают из коробки;
    • сайт собирается за пару секунд, настройка сводится к одному mkdocs.yml;
    • сайт у меня небольшой, и научных возможностей Sphinx мне не нужно.

    Вывод меняется, если нужны:

    • нумерация формул и рисунков с перекрёстными ссылками, BibTeX, печатная версия в PDF — тогда Sphinx;
    • исполнение ноутбуков при сборке — Sphinx с MyST-NB или Quarto;
    • простой блог без научного оформления — Pelican или Nikola.
